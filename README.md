# موقع شام ترافل للسياحة والسفر - Sham Travel

موقع ثابت (HTML / CSS / JavaScript) بدون أي مكتبات أو إطار عمل.

## التشغيل
افتح `index.html` مباشرة بالمتصفح، أو ارفع المجلد كاملاً على أي استضافة (Netlify، GitHub Pages، cPanel…).

## الصفحات
| الملف | الصفحة |
|---|---|
| index.html | الرئيسية |
| about.html | من نحن |
| services.html | الخدمات (8 خدمات مع تفاصيل) |
| packages.html | الباقات + فلترة + نافذة تفاصيل |
| booking.html | نموذج حجز من 4 خطوات يُرسل الطلب على واتساب |
| guide.html | دليل المسافر + الأسئلة الشائعة |
| contact.html | التواصل + نموذج رسالة + خريطة |

## التعديل السريع — كل شي من ملف واحد: `js/data.js`
- **SITE**: رقم الهاتف، الواتساب، الإيميل، العنوان، أوقات الدوام، روابط فيسبوك وانستغرام، موقع الخريطة.
- **SERVICES**: الخدمات ونصوصها.
- **PACKAGES**: الباقات (الاسم، السعر، المدة، المميزات، البرنامج، الفنادق).
- **TESTIMONIALS**: آراء العملاء (حالياً نماذج للعرض — استبدلها بآراء حقيقية).
- **FAQS**: الأسئلة الشائعة.

الهيدر والفوتر مشتركين لكل الصفحات وموجودين بـ `js/main.js`.

## الألوان
بـ `css/style.css` أول الملف (`:root`) — أزرق سماوي وأبيض متطابق مع اللوغو.
